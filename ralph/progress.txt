## Codebase Patterns
- Use `override` keyword for all methods that override base class methods (required by `noImplicitOverride` in `tsconfig.json`).
- Use `AiProviderOptions` interface from `ai-providers/base-ai-provider.ts` for AI provider `call` methods.
- The `as` operator is strictly banned; use proper typing or `@ts-expect-error` if absolutely necessary.
- Avoid the string " as " (with spaces) in comments and strings as it triggers the `no-ts-as-operator` linter.
- Always run `yarn build` after code changes to keep `dist/linter.mjs` updated.
- Use local variables for private fields after null checks to satisfy strict TSC null checks.
- Explicitly declare all class properties, especially in base classes.
